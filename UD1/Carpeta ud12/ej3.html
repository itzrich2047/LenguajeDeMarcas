Ficha técnica: HTML

¿Qué es?

HTML lenguaje de marcado estándar utilizado para estructurar y desplegar páginas web y sus contenidos.

Versión actual

HTML5 es la 5a versión de HTML.

La fecha de publicación de HTML5: 28 de octubre de 2014.

Características

Para crear un documento HTML se utilizan etiquetas que delimitan el contenido y le dan significado.
Por ejemplo, la etiqueta <h1> se utiliza para definir un encabezado de nivel 1, y la etiqueta <p> sirve para definir un párrafo.

Curiosidad técnica

Para poder ordenar todo el código, se puede utilizar Shift + Alt + F.
