# UD 3.1 · Posicionamiento y overflow

## Ejercicio 1. Laboratorio de position

### Static:

#### ¿Se mueve? ¿Por qué?

No se mueve, porque no tiene posición relativa ni absoluta

### Absoluta: 


#### ¿A qué esquina va? 

Se va a la esquina superior derecha.


#### ¿Qué cambia?
El c3 se posiciona respecto a este contenedor, porque es el primer padre con posición relativa.


#### ¿Y qué hacen los demás cuadros con el hueco de c3?
Los demás se posicionan respecto a este contenedor
