# UD2.1 - Ejercicio 5

## Parte A - Detectove de colisiones

### Predicción

| Elemento | Color previsto | Razonamiento |
|---|---|---|
|`<h1 id="titulo" class="grande">` | **brown** | Porque el `#título` es el que dirige su color sobre esa línea. |
| `<p class="aviso">Texto 1` | **purple** | Porque el `p.aviso` es el dirige su color en esa línea. |
| `<p class="aviso" id="importante">Texto 2` | **black** | Este es simplemente por tener un id único en todo el código por lo tanto define su color |
| `<div><p>Texto 3` | **orange** | Porque el `div p` es el que dirige su color en ese div |
